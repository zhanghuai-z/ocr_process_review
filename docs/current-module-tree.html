输入与项目模块

把用户文件变成具有稳定身份的页面集合。只处理来源、页面图像和项目生命周期，不解释版面或 OCR 内容。

页面来源真值
01
Source Intake文件接收层

接收图片或 PDF，记录原始来源；不会把临时目录当作业务身份。

输入
02
Page Materialization页面实体化层

生成稳定页面图像、尺寸、页码和页面 UID。

Page
03
Project Session项目会话层

管理当前项目绑定路径、保存、另存为和关闭，不引入用户不可见的项目真值。

持久化边界

版面理解模块

将 Paddle VL 的自动观察转成当前版面事实，并允许人工对框、类型和顺序进行修正。

LayoutSnapshot
01
Vendor Observation供应商观察层

保留 VL1.6 原始块、标签、文本和坐标，作为不可变证据。

Raw Artifact
02
Layout Normalization版面标准化层

把供应商字段转换为统一块类型、坐标和来源信息，不加入业务 fallback。

Normalized
03
Layout Truth版面真值层

形成当前页面的块身份、属性、bbox、顺序和 OCR policy。

唯一可写事实
04
Manual Layout Edit人工编辑层

新增、删除、移动、改类型和合并框；所有修改只通过统一编辑命令进入版面真值。

Command

CharOCR 前路由模块

读取版面事实、PP-OCRv6 行观察和页面像素，生成 CharOCR 唯一可消费的页面执行计划。

PageRoutingPlan
01
Prepass ObservationPP 行观察层

提供原始行种子、文本提示、方向、角度与 mask；原始观察保持只读。

PP-OCRv6
02
Layout Ownership版面归属层

确定每条 PP 行属于哪个文本块，并标出公式、表格和图像等排除区域。版面框只决定归属，不裁文字。

Ownership
03
Structural Exclusion结构排除层

公式、表格、图片只声明自身区域不可送入文本 OCR，不反向改变物理行几何。

Masks
04
PhysicalLineGeometryResolver物理行几何层

合并同一物理行的 PP 碎框，为前景组件建立唯一行归属，并一次性确定最终四边；阅读轴保留 PP 行包络并允许补全，横截面按真实墨迹收紧。

新增/替换
05
Text Script Partition文字分流层

在物理行稳定后，将可识别区域分为 Latin/Digit 与 Other，决定 EngCut 和 LineCut 输入。

Segments
06
Plan Compiler计划封装层

把块、物理行和分段封装成不可变执行计划，不再重新推测几何或版面属性。

Routing Plan
07
Route Validation路由门禁层

发现未归属、重复归属或非法重叠时只阻断对应页，并给出明确问题，不静默 fallback。

Page Gate

字符 OCR 模块

只执行已经通过门禁的 OCR 输入，不重新解释版面，不自行寻找公式或修改路由。

Native Boundary
01
Dispatch执行分派层

按照计划把 Latin/Digit 送往 EngCut，把 Other 送往 LineCut。

Deterministic
02
Native Adapter原生桥接层

管理 DLL/进程调用、输入图像、并发和 native cache，不泄露到业务模型。

External Engine
03
Result Translation结果翻译层

把原生返回转为统一文本、字符候选、置信度和 bbox 观察。

NativeOcrResult

识别观察模块

把 OCR 引擎结果整理成可审计的识别事实。它是机器观察，不是人工终稿。

OcrObservation
01
Line Observation行观察层

保存行级文本、bbox、来源和置信度，并关联版面块与路由来源。

Line
02
Character Observation字符观察层

保存字符文本、字符框、token 来源和识别分支。

Char
03
Geometry Reconciliation字符几何协调层

用像素证据处理大字、重叠框和碎框；优先保证字符几何正确，不篡改版面真值。

Geometry
04
Observation Persistence观察持久化层

将机器观察与来源证据一起保存，支持重新 OCR 和审计。

Persist

人工校对模块

横校和纵校是同一份人工校对事实的两个视图。页面、字符集合和裁图都是引用上下文，不是独立文本分支。

ProofState
01
Proof Index校对索引层

根据 OCR 观察建立页面行索引、字符索引和相同字集合，不复制人工文本。

Projection
02
Horizontal View横校视图层

按行对照原稿与文本，提交对共享终稿的编辑命令。

View
03
Vertical View纵校视图层

按字符集合检查同字差异，读取同一上下文并提交同一种编辑命令。

View
04
Proof Commit校对提交层

统一处理文本、状态、probe、撤销和冲突，只有提交点可以修改人工终稿。

Commit
05
Proof Persistence校对持久化层

按作用域事务保存终稿与关联状态，不重写未变更行。

Transaction

导出与归档模块

只消费已确定的版面、OCR 观察和人工终稿，生成格式中立 IR，再输出具体文件。

ExportIR
01
Export Projection导出投影层

选择最终文本、结构元素、页面顺序和来源引用，不修改项目事实。

Projection
02
Export IR格式中立层

统一表达段落、标题、公式、表格、图片、字符几何和溯源。

IR
03
Format Renderer格式渲染层

分别生成双层 PDF、Markdown、DOCX、HTML、XML 等文件。

Output
04
Archive归档层

保存项目、原始证据和导出成果，保证后续能够重开与追溯。

Archive
