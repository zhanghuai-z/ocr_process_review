# Intentional CJK Spacing Audit

The 68-page project confirms that OCR text alone does not preserve intentional
Chinese tracking consistently. Both Paddle VL and PP-OCR may return `目录`, while
the persisted CharOCR geometry clearly separates `目` and `录`.

An external audit compared adjacent CJK character center distance with the
median character height of each reliable horizontal line. The sample has a
natural empty interval between ratios 2.1 and 2.2. Using 2.1 only as an audit
boundary found 232 candidate lines: 197 on the first eight contents pages, 33
repeated running headings, and two other visually spaced lines.

This proves that character geometry can identify visible spacing. It does not
decide whether layout tracking belongs in normalized exported text. Production
integration therefore still requires an explicit text policy.

The saved sample also contains directory leader remnants such as `……` in
`line.text` and `char_`. Those characters came from CharOCR and are not produced
by the spacing audit. They must be excluded by the directory-decoration route
before OCR; the spacing audit must not silently delete them.

Artifacts are generated by `scripts/audit_intentional_cjk_spacing.py` and are
kept outside production state.
